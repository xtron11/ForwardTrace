### Message flow
1. `prepare_message`: 403 `email_not_verified` (if `settings.require_verified_email`); text -> strip, 422 `empty_text`, 422 `text_too_long` (> `max_text_chars`=4000); audio -> `audio_store.extension_for(content_type)`; `get_or_create_today`; 409 `reply_in_progress` if `conversation.id in _busy`; `limits.ensure_can_message` (402 `limit_reached`); allocates `message_id=uuid4()`; saves audio to `AUDIO_DIR/<user_id>/<message_id>.<ext>`; adds to `_busy` (module-level `set[uuid.UUID]`, in-process, one worker). Returns `PreparedMessage(user_id, conversation_id, message_id, source "text"|"voice", text, audio_path, audio_mime, started, plateau_only)`.
2. `stream_reply(prepared, *, plateau=False)` sets `prepared.started=True`, creates `asyncio.Queue` + task `_run_reply` (kept in `_tasks`), returns async generator reading the queue. `_run_reply` opens `async with SessionLocal() as db:` (own session; request session already closed) -> `_reply(db, prepared, emit, plateau)`; on any exception emits `error` `{code: "llm_failed", message}`; `finally: _busy.discard(...)`, queue sentinel None. A closed client stops the reading, not the task.
3. `_reply`: load user+conversation (gone -> `error llm_failed`); `plateau_only` -> `_plateau_reply`; else build user `Message(id=prepared.message_id, role="user", source=...)`; voice: `transcribe(path, mime, user.locale)` inside `costs.track() as stt_usage` (errors: `stt_failed`; transcript < `no_speech_min_chars`=10 -> `no_speech`; sets words, audio_path, audio_mime, audio_seconds, detected_language, stt_ms); `content_raw=text`, `content=[{"type":"text","text":text}]`, `costs.charge_message(message, stt_usage)`. Then `conversation.counts_for_limit=True`, `user.outreach_unanswered=0`, unreplied `Outreach` rows of the day get `replied_at` + event `outreach_replied {outreach_id, topic, message_id}`; event `message_sent {message_id, source, words, kind}`; commit; emit `user_message`.
4. Safety (`safety.safety_check(text, user.locale)`, SAFETY_MODEL via `complete_json_with`) inside `with costs.track() as usage`; failure -> level 0, event `safety_check_failed`; sets `message.safety_level`, `conversation.safety_level=max(...)`; level>=2 -> event `safety_flag {level,message_id,conversation_id}`.
5. Branching order: (level<2 and `first_conversation.in_first_conversation`) -> `_first_reply`; level>=3 -> `_template_reply` (`safety.level3_text(user)`, no model, kind `safety_template`); level==2 -> `_stream_and_save` with `ChatContext(messages=safety.level2_messages(locale, history), known={})`, `safety_reply=True`; else normal: mode = "plateau" if `plateau` arg or the previous assistant message `intent=="plateau"` (event `plateau_triggered` only when `plateau` arg) -> `build_context(db,user,conversation,text,mode=,soft=level==1)` -> `_stream_and_save(..., suggest_help=level==1)`.

### Context assembly: `build_context(db, user, conversation, text, *, mode="normal"|"plateau", soft=False) -> ChatContext(messages, known: dict[str,Fact], recalled: set[str])`
- goal = `_active_goal` (latest `Goal.is_active`).
- normal: threads = open `Thread`s ordered by `coalesce(last_mentioned_on, opened_on) desc`, limit `context_threads`(5); facts = `memory.relevant_facts(db,user_id,text,context_facts=5)` (embedding cosine if `EMBEDDING_MODEL` set, topped up by latest by date; skips `flagged_at`).
- plateau: threads=[], facts from `_plateau_evidence` (up to `plateau_max_pairs`=3 pairs with biggest gap, closed threads limit `context_threads`, conversation count with `counts_for_limit`; if pairs+closed < 2 adds earliest 2 `level` facts and `days_to_compare`), `prompts.plateau_note(...)`; no day summaries.
- history = `messages_of(conversation)` ordered by (created_at,id); fact ids used today by assistant messages (`used_fact_ids`) are added to `known` so history quotes still render; `recalled` = fact ids in `Pair.recalled=True`.
- days = up to `context_days`(3) earlier `Conversation`s with `summary` not null, newest first, reversed to chronological.
- `prompts.chat_system(user.locale, skill=user.skill or goal.title, anchor_quote=goal.why_text, finish_line=goal.finish_line, threads=["[id] title (open since date)"], facts=["[id] date type: \"quote\""], days=["date: summary"], max_words=settings.reply_max_words, soft, plateau, plateau_block)`.
- messages = `[{"role":"system"}]` + every history message via `_plain(message)` (content_raw, else segments with quotes as «…»), roles user/assistant. Current-day messages are in history (the new user message was committed before).

### Streaming/rendering
- `_stream_and_save`: `renderer = ReplyRenderer(context.known, recalled=context.recalled)`; `async for chunk in stream_chat(context.messages)` (no model/effort args -> llm defaults CHAT_MODEL/CHAT_REASONING_EFFORT); `LLMError` -> `error llm_failed`; empty segments -> `error llm_failed`. For level 2 meta forced to `{"quick_replies": [], "intent":"normal"}`. If `suggest_help` and `safety.should_suggest_help` -> appends `"\n\n"+t(locale,"safety.suggest_help")` as `delta`, event `safety_suggest_help`. Saves assistant `Message(source="text", content_raw, content=segments, quick_replies, used_fact_ids, intent, model_name=settings.chat_model or openai_model, llm_ms, created_at=_now())`, `costs.charge_message(answer, usage)`, event `ai_reply`, then rule check, commit, emit `done`.
- `ReplyRenderer(known, recalled)`: `feed(chunk)->[(event,data)]`, `flush()`, `finish()->RenderedReply(content_raw, segments, used_fact_ids, meta)`. Text before `{{` streams as `delta {"text"}`; `{{...}}` held until `}}`, matched by `_PLACEHOLDER = ^\s*quote\s*:\s*([0-9a-fA-F-]{32,36})\s*$`; if UUID in `known` -> segment from `quote_segment(fact, recalled=)` and event `quote` (segment minus "type"); otherwise silently dropped (also unclosed `{{` dropped with all after). content_raw keeps `{{quote:<id>}}`. Everything after `<<<META>>>` (`prompts.META_SEPARATOR`) is buffered, not streamed; held-suffix logic avoids leaking partial markers. Trailing whitespace is held back.
- `_parse_meta`: strips ``` fences, json.loads or first `{`..last `}`; `quick_replies` = non-empty strings, each `[:80]`, max `max_quick_replies`=5; `intent` in ("normal","plateau") else "normal"; broken/missing -> `{"quick_replies": [], "intent": "normal"}`.
- `quote_segment(fact, *, recalled=False)` -> `{type:"quote", fact_id, quote, local_date (iso), recalled, message_id, audio_start_ms, audio_end_ms}`.

### SSE events (`sse(event, data)` = `event: x\ndata: <json, ensure_ascii=False>\n\n`)
