## Что должно заработать

Этап 3 брифа. Через 30 минут тишины и при закрытии дня в 04:00 по времени человека из разговора извлекаются проверенные факты (`achievement`/`struggle`/`learned`/`level`), открываются, упоминаются и закрываются нити, пишется выжимка дня. Для голосовых сообщений цитата выравнивается по словам — у факта появляются `audio_start_ms`/`audio_end_ms`. Новые факты получают эмбеддинги (если задан `EMBEDDING_MODEL`); контекст ответа подбирает факты, ближайшие по смыслу, а без эмбеддингов — последние по дате. В конце извлечения создаются пары «было → стало»: из закрытой нити и по сходству.

## Из брифа, дословно

> «Цикл в `lifespan` раз в 5 минут находит разговоры, где последнее сообщение старше 30 минут, а `memory_extracted_at` пусто или раньше последнего сообщения, и запускает `extract_memory`. Второй цикл закрывает день в 04:00 по времени человека…»
> «Каждую цитату проверить `verify.py` по тексту своего сообщения. Не прошла — факт отброшен, счётчик пишется в событие `memory_dropped_facts`. `message_id` не из этого разговора — факт отброшен.»
> «`open`: создать нить, только если ссылка на факт `struggle` прошла проверку. `mention` и `close` принимаются только для `thread_id` из переданных открытых нитей. `close` требует факт `achievement` или `learned`.»
> «Пары «было → стало» создаются в конце `extract_memory`» (пункты 1–4)
> «Поиск по смыслу. Эмбеддинги фактов хранятся в `facts.embedding` как JSON, а косинусное сходство считается в Python … Если эмбеддинг не удалось получить, факт сохраняется без него, а поиск откатывается на последние по дате факты.»
> «Готово, когда тесты проверяют: непроверенная цитата отброшена и посчитана; нить нельзя закрыть чужим или выдуманным `thread_id`; ошибка эмбеддингов не ломает извлечение; выравнивание даёт верные `audio_start_ms` и `audio_end_ms` на фикстуре; закрытая нить старше 7 дней и близкие по смыслу факты создают пару, а пара не дублируется.»

Полный текст: бриф — «Память: `extract_memory()` и `close_day()`», «Поиск по смыслу», «Термины», «Этап 3», строка `GET /api/memory` в «API».

## Критерии приёмки

- [ ] `extract_memory` по JSON-схеме брифа; непроверенная цитата и чужой `message_id` отброшены, `memory_dropped_facts` с числом (тест)
- [ ] Нити: открытие только со `struggle`; `mention`/`close` только для переданных открытых нитей; закрытие только с `achievement`/`learned`; чужой или выдуманный `thread_id` ничего не меняет (тест); `last_mentioned_on` обновляется
- [ ] Выравнивание цитаты по `messages.words` даёт верные мс на фикстуре; без точного выравнивания — null (тест)
- [ ] Эмбеддинги одним запросом; ошибка эмбеддингов не ломает извлечение (тест); пустой `EMBEDDING_MODEL` — без запроса
- [ ] `relevant_facts`: по косинусу, иначе по дате; только проверенные без `flagged_at`; используется в контексте ответа
- [ ] `summary` ≤ 200 символов и `memory_extracted_at`; повторный запуск по тому же разговору не дублирует факты (совпадение цитаты), в т.ч. факты первого разговора
- [ ] Пары: закрытая нить с разницей ≥ `PAIR_MIN_DAYS` → `thread_closed`; новое `achievement` → ближайший `struggle` старше 7 дней с косинусом ≥ `PAIR_MIN_SIMILARITY` → `similarity`; не больше одной пары на факт; повтор не дублирует (тест); `theme` из нити или `complete_json`
- [ ] Циклы памяти и закрытия дня в `lifespan`, идемпотентны, переживают исключения; функции принимают `now` (тест выбора разговоров)
- [ ] `GET /api/memory` — цель, нити, последние 50 фактов; тест изоляции
