## Что должно заработать

Этап 4 брифа. Новый человек открывает «Сегодня», и ИИ ведёт его по шагам: навык → мотивация (дословная цитата и 4 варианта финиша быстрыми ответами + «Без финиша — хочу просто расти») → где вы сейчас и с чего начинали → первое «тогда → сейчас» с цитатами «по вашим воспоминаниям» (пары `recalled = true`, факт `level`) → во сколько написать завтра. Ответы идут тем же потоком: одно `delta` с полным текстом и `done` с быстрыми ответами. Пустой или нерелевантный ответ — один мягкий повтор, затем дальше. Цель, мотивацию и финиш можно поправить через `PATCH /api/goal`. Все русские тексты — на «вы» (`spec.md` §6).

## Из брифа, дословно

> «Первый разговор заменяет экраны онбординга: после регистрации человек сразу попадает на «Сегодня», где ИИ начинает разговор. Состояние хранится в `conversations.state`…»
> Шаги 1–6 раздела «Первый разговор» (создание, skill, motivation, finish, baseline, schedule)
> «Если ответ пустой или не по теме, ИИ переспрашивает один раз мягче (`retries`), затем переходит к следующему шагу. Цель, мотивацию и финиш потом можно изменить в профиле.»
> «Готово, когда тесты покрывают все шаги; варианты финиша приходят быстрыми ответами; свой вариант финиша и «Без финиша» сохраняются верно; ветку «только начал»; повторный вопрос при пустом ответе; непрошедшую проверку цитаты мотивации; сравнение без пар; создание фактов `level` и пар с `recalled = true`.»
> Дополнение: «Всегда обращаться на вы»

Полный текст: бриф — «Первый разговор», «Этап 4», строка `PATCH /api/goal` в «API».

## Критерии приёмки

- [ ] Тест каждого шага: skill → `users.skill`, `goals.title` (длинный ответ сокращается); motivation → цитата проверена `verify`, `why_text`, `why_message_id`, 4 варианта финиша + «Без финиша» в `quick_replies`
- [ ] Непрошедшая проверку цитата мотивации → ответ без цитаты (тест)
- [ ] finish: вариант кнопкой и свой текст → `finish_line`, `finish_set_on`; «Без финиша» → `finish_line = null`, `no_finish = true` (тесты)
- [ ] baseline: до 3 пар, все цитаты проверены, факты `struggle`/`achievement` + `pairs` (`recalled = true`, `source = first_conversation`), `level_quote` → факт `level`; события `quote` с `recalled: true`; ветка без пар / «только начал» (тесты)
- [ ] schedule: «Вечером» → 21; «После занятия» → уточнение и разбор часа; «Выберу время» → час «HH:00»; неразобранный — повтор, затем 20; в конце `first_conversation_done = true`, `step = done` (тесты)
- [ ] Пустой/нерелевантный ответ — один мягкий повтор, затем следующий шаг (тест)
- [ ] Незавершённый первый разговор продолжается на следующий день с того же шага (тест)
- [ ] `PATCH /api/goal` `{title?, why_text?, finish_line?}` (null — без финиша) → `GoalOut`; тест изоляции
- [ ] Русские строки шагов — на «вы», без форм с родом
