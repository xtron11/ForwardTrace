## Что должно заработать

Этап 7 брифа. Каждое сообщение человека (включая первый разговор) проходит проверку безопасности 0–3: уровень 1 — ответ мягче и, при частой усталости, редкий совет обратиться к специалисту; уровень 2 — отдельный промпт без памяти и прогресса; уровень 3 — шаблон без модели с контактами помощи по стране (пустые — общая рекомендация, без выдуманных номеров) и пауза сообщений ИИ первым. «Кажется, я стою на месте» по кнопке и по `intent = plateau` строит ответ на доказательствах. Лимит: 7 дней без ограничений, затем 3 разговора в неделю; сверх — 402 и пейволл «Продолжить с Plus» → месяц безлимита («Мы в бете — вам месяц бесплатно»). Выгрузка `GET /api/me/export`. Набор эталонных диалогов и скрипт их прогона.

## Критерии приёмки

- [ ] `safety_check` через `complete_json_with(model=SAFETY_MODEL)`; ошибка → 0 и событие `safety_check_failed` (тест)
- [ ] Уровень 1 — пометка «мягче» в контексте; совет специалисту по правилу 5 из 14 / раз в 14 дней, событие `safety_suggest_help` (тест)
- [ ] Уровень 2 — `SAFETY_SYSTEM` без памяти и прогресса (тест проверяет содержимое переданных модели сообщений); `conversations.safety_level`, `safety_flag`
- [ ] Уровень 3 — шаблон без вызова модели (тест), контакты по `users.country` или общая рекомендация; outreach не отправляется до следующего сообщения человека
- [ ] Первый разговор: уровень ≥ 2 → протокол безопасности, шаг не продвигается (тест)
- [ ] plateau по кнопке и по `intent = plateau`: только якорь, до 3 пар с наибольшим разрывом, закрытые нити, число разговоров; меньше двух доказательств — опора на точку старта и срок до сравнения; не засчитывает день (тест)
- [ ] Лимит: пробные 7 дней, 3 в неделю пн–вс в поясе человека, засчитанный сегодня день не блокируется, `plus_until ≥ сегодня` снимает; тесты на границе недели и в разных поясах; 402 `limit_reached` до потока
- [ ] `POST /api/paywall/click` → `plus_until = сегодня + PLUS_BETA_DAYS`, `paywall_clicked`; пейволл на фронтенде по `limit_reached` с «Продолжить с Plus» и экраном «Мы в бете — вам месяц бесплатно», `paywall_viewed`; обещает только безлимит
- [ ] `GET /api/me/export` — JSON-файл (разговоры, сообщения, факты, нити, цель) только владельца (тест)
- [ ] `tests/eval/dialogs.yaml` — заготовка 50 диалогов (10 дистресса); `scripts/eval_dialogs.py` проверяет длину, один вопрос, `BANNED`, известные `fact_id`, уровень безопасности, выдаёт отчёт; без ключа — понятное сообщение
