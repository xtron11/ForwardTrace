## Известные баги

- Модель иногда пишет о человеке в мужском роде («ты решил») и копирует пример промпта дословно (проверка 2026-10-27)
- Текст факта памяти может содержать интерпретацию, которой человек не говорил; цитата при этом верна
- На живом первом разговоре «сейчас A2… год назад не мог связать двух слов» пара «тогда → сейчас» не создалась
- Обрыв связи, когда ответ ИИ не получился: «Повторить» не даёт нового ответа (`conversation.py:537-553`)
- Одновременный повтор с тем же `client_msg_id` из двух вкладок может получить 409; повтор через `IntegrityError` не пишет `message_duplicate`
- На каждый ответ читается до 24 000 сообщений истории (`conversation.py:305`)
- Подтверждение удаления факта обещает «больше не будет использоваться» — прошлые ответы с цитатой остаются (`lib/i18n.ts:612`)
- Тест тона `test_v2_dialogue_tone.py:80-99` привязан к промпту v2.0
- «Помогло / Не то» скрыты весь день первого разговора; шаг «финиш» принимает любой текст
- Загрузка аудио пишется во временные файлы до проверки лимита
- Черновик голосового живёт в памяти процесса: после перезапуска его файл остаётся на диске без хозяина (удалится только со стиранием аккаунта), а сообщение уйдёт текстом без записи
- Быстрый ответ во время распознавания не блокируется; текст из записи потом встанет в поле
- `POST /api/events` принимает серверные типы событий; `PATCH /api/auth/me` с `null` → 500 на Postgres
- Ручная страна перезаписывается при смене пояса; имена FK в `models.py` и 0014 расходятся
- Извлечение памяти при постоянной ошибке модели повторяется без ограничения
- Месячная сводка только 1-го числа; thin шлёт «готова»; ссылка на `/today`
- Telegram: нет дедупликации по `update_id`; голосовой ответ боту без теста
- Фронтенд: уход со «Сегодня» не прерывает поток; провал обновления токена не уводит на `/login`; быстрый ответ во время записи теряет запись; неверная дата в URL роняет страницу; выгрузка без сети зависает; `Goal.criteria` в типах
- Ручное переключение темы не меняет цвет полосы браузера (`lib/theme.ts`)
- Стоимость в админке без фоновых вызовов; `model_name` на шагах первого разговора без модели
- Лендинг: форма с родом в тексте для скринридера
