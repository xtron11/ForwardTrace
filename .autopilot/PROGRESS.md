## Известные баги

- Шаг «во сколько написать» первого разговора принимает ответ с цифрой не по теме («уровень B1») как час 01:00 без переспроса
- «Помогло / Не то» скрыты весь день первого разговора, и под обычными ответами после онбординга
- Шаг «финиш» принимает любой текст как финиш
- Ручное переключение темы не меняет цвет полосы браузера при второй meta theme-color (`lib/theme.ts`)
- Загрузка аудио любого размера сначала пишется во временные файлы, лимит проверяется после
- `POST /api/events` принимает серверные типы событий от клиента
- `PATCH /api/auth/me` с `null` в `outreach_channel`/`timezone`/`locale` → 500 на Postgres
- Ручная страна перезаписывается при смене пояса, если совпала со страной старого пояса
- Имена FK в `models.py` и миграции 0014 расходятся (goals, threads)
- Извлечение памяти при постоянной ошибке модели повторяется без ограничения
- Месячная сводка: собирается только 1-го числа (пропуск месяца, если сервер лежал); thin тоже шлёт «готова»; ссылка ведёт на `/today`
- Telegram: нет дедупликации по `update_id`; голосовой ответ боту без теста
- Фронтенд: обрыв сети посреди ответа предлагает повторить уже сохранённое сообщение; уход со «Сегодня» не прерывает поток; провал обновления токена не уводит на `/login`; быстрый ответ во время записи теряет запись; неверная дата в URL роняет страницу; выгрузка без сети зависает; `lib/types.ts` держит `Goal.criteria`
- Стоимость разговора в админке без фоновых вызовов; первый разговор пишет `model_name` на шагах без модели
- Лендинг: «стоял прежде… его собственные даты» в тексте для скринридера — форма с родом
