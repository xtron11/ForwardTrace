# 0008. Выбор модели — отдельная функция рядом, а не новые параметры

## Контекст
Проверке безопасности нужна своя модель и свой уровень рассуждения. Все вызовы JSON-ответов идут через `complete_json(system, user, schema)`, и тесты подменяют её по имени модуля заглушкой с теми же тремя аргументами.

## Решение
Сигнатура `complete_json` не меняется. Рядом добавляется `complete_json_with(system, user, schema, *, model, reasoning_effort=None)`; обе используют общую внутреннюю функцию запроса. Потоковый `stream_chat` — отдельная функция.

## Почему
Рассмотрено: добавить необязательные `model` и `reasoning_effort` в `complete_json` (так предполагал один из разделов спецификации). Не подошло: модули импортируют функцию по имени, и подмены в тестах — заглушки с тремя аргументами; смена сигнатуры затрагивала бы всех вызывающих и все подмены.
Отдельная функция оставляет существующих вызывающих как есть.

## Последствия
- Две функции делают почти одно и то же; их легко разнести при будущих правках.
- Модуль безопасности подменяется в тестах отдельно от остальных.
- Различие между ними — только модель и уровень рассуждения, механика общая.
