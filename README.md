# ForwardTrace

Человек тридцать секунд наговаривает, как прошёл день. Система распознаёт речь,
извлекает из рассказа факты, **проверяет каждый по дословной цитате** и через несколько
дней собирает отчёт о том, что за это время изменилось.

Продукт отвечает на один вопрос: будет ли человек регулярно давать немного информации в
обмен на доказательство того, что он движется вперёд. Всё в коде подчинено этому
вопросу.

> Главная техническая идея — не просить модель не выдумывать, а проверять её постфактум.
> Каждый извлечённый факт обязан нести фрагмент транскрипта, и если этого фрагмента в
> расшифровке нет, факт отбрасывается до записи в базу. Числа модель не считает никогда:
> все суммы и серии вычисляются в SQL.

---

## Как это работает

```
голос (30 секунд)
  → распознавание речи (Deepgram Nova-3)
  → человек правит расшифровку, если что-то расслышано не так
  → извлечение фактов моделью под JSON-схемой
  → проверка каждого факта по цитате из расшифровки
  → активности, победы, помехи и намерения в базе
  → недельный отчёт и месячная выжимка
```

## Из чего состоит

| Часть | Что это | Где |
|---|---|---|
| Бэкенд | REST API на FastAPI, фоновые задачи в том же процессе, серверная HTML-админка | [`progress-backend/`](progress-backend/) |
| Фронтенд | Next.js 16 (App Router), все экраны клиентские, PWA с push-уведомлениями | [`progress-frontend/`](progress-frontend/) |
| Лендинг | Статический HTML/CSS/JS, отдаётся фронтендом по адресу `/` | [`progress-frontend/public/landing/`](progress-frontend/public/landing/) |
| База | PostgreSQL 16, схемой управляет Alembic (в тестах — SQLite) | `progress-backend/alembic/` |

## Быстрый старт

Нужны Python 3.11+, Node 20+ и Docker Desktop. Три окна терминала:

```powershell
# 1. база
cd progress-backend
docker compose up -d db

# 2. бэкенд
alembic upgrade head
python -m uvicorn app.main:app --reload

# 3. фронтенд
cd ../progress-frontend
npm install
npm run dev
```

Приложение открывается на `http://localhost:3000`, документация API — на
`http://127.0.0.1:8000/docs`.

Подробная инструкция со всеми подводными камнями Windows — в [RUNNING.md](RUNNING.md).
Ключи для `.env` брать из `progress-backend/.env.example`.

## Состояние

Ранняя стадия: продукт рассчитан примерно на десяток пользователей, отобранных вручную,
и многое сделано под этот масштаб сознательно. Перед публичной регистрацией нужно
закрыть как минимум это:

* восстановление пароля — сейчас забывший пароль теряет аккаунт навсегда;
* ограничение частоты запросов на вход, регистрацию и админку;
* удаление аккаунта и выгрузку данных: мы храним голосовые записи;
* очередь задач вместо фоновых задач внутри процесса приложения;
* внешнее хранилище для аудио и резервное копирование базы.

Полный список с причинами — в разделе «Известные ограничения»
[DOCUMENTATION.md](DOCUMENTATION.md) и в конце README бэкенда.
